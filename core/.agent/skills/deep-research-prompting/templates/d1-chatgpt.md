## Portal Setup

1. Turn **Lockdown Mode** off; it blocks deep research.
2. Start deep research: type `/Deepresearch`, or pick it from the `+` tools menu or the sidebar,
   in Chat or in the **Work tab** (paid plans).
3. Add only the **Plugins** (apps) the topic needs; deep research uses them read-only, and not
   every plugin supports it.
4. When the topic has authoritative domains, list them under Sites → **Manage sites**.
5. Paste the prompt. When the research plan appears, edit it until it matches
   `## Expected Research Plan`, then start.
6. Download the report as Markdown and save it as `output-chatgpt.md`.

## Objective emphasis

Competition and breadth: crawl many platforms (Reddit, HN, GitHub, forums, vendor docs);
quantitative comparison tables — pricing, feature matrices, benchmark numbers, star and download
counts; community sentiment with quoted excerpts.

## Deliverable

A Markdown report: a competitor comparison table (name, pricing, licence, key features, activity
signals, source URL per row), a community-sentiment section with quoted excerpts, and the
`## Sources` appendix.

## Expected Research Plan

- Enumerate the competitors and alternatives, including open-source and niche ones.
- Collect pricing, licence and feature data from each vendor's own pages.
- Collect activity signals (stars, releases, downloads) with dates.
- Sample community discussion on at least three platforms.
- Build the comparison table, then mark gaps as [UNVERIFIED].
