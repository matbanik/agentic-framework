## Portal Setup

1. Use Claude on web or desktop, not mobile; mobile skips connectors without telling you.
2. In the model menu next to the send button, set **Effort** to High or above. Research runs on
   its own fixed model, so the model choice does not matter.
3. Start research: type `/deep-research`, or click `+` → Research. In the previous experience,
   turn web search on and click Research.
4. Connect only the sources the topic needs (for example Google Workspace).
5. Paste the prompt. The portal shows no editable plan, so `## Expected Research Plan` travels
   inside the prompt as the steps Claude must cover.
6. Save the report text as `output-claude.md`.

## Objective emphasis

Strategy and differentiation: multi-branch reasoning; an ERRC grid (Eliminate / Reduce / Raise /
Create); architecture pattern recognition; an explicit statement of the strongest
counter-argument to its own conclusion.

## Deliverable

A Markdown report: a positioning analysis, an ERRC grid, two or three strategic options with
trade-offs, the strongest counter-argument to the recommended option, and the `## Sources`
appendix.

## Expected Research Plan

- Map the existing approaches and the architecture patterns behind them.
- Identify where users are under-served and why incumbents do not serve them.
- Build the ERRC grid from that evidence.
- Develop two or three options and test each against the evidence.
- State the strongest counter-argument to the recommendation, with sources.
