### Evidence-First & Sequencing Rules

- **Evidence-first completion:** a row is `[x]` only when its deliverable exists and the handoff carries its evidence.
- **Red first:** each coder row writes its tests before the code and records the red run in the handoff.
- **The review barrier:** the handoff (H1-6) comes before the review, and the H2 artifacts come after `approved`.
- **No self-review:** the implementer dispatches the H1-7 review and never authors its verdict.
- **`[B]` is evidence-gated:** it is allowed only for a reproduced external error, a missing dependency, credential or permission, or a human-decision gate, each with a `### B-<row-id>` block.
- **Valid stops:** the only sanctioned stops are DONE, the review cap, an unavailable reviewer, or a human decision. Compaction continues the pass.
